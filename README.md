# Eleventh Creative Vercel Site

Static Vercel-ready rebuild of the Manus reference site.

## Deploy

Import this folder or its Git repo into Vercel. No install command or build command is required.

- Framework preset: Other
- Build command: leave blank
- Output directory: leave blank

## Update Photos

Edit the image URLs in `app.js` inside the `images` object and `workItems` array.
